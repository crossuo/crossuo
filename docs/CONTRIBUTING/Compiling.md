# Compiling

This project requires CMake 3.12 to build. It currently supports Visual Studio 2015/2017/2019, GCC 7+ and Clang 7+. Cross-compilation to Win/Arm available. 

### Dependencies

Some platforms may require extra dependencies, we try to avoid them to simplify the building process.

### Building

Use `./scripts/deploy.sh`
